# 회의 자료 탐색 지침

- 먼저 [README](README.md)를 읽고 사용자 질문에 필요한 문서만 선택한다.
- 결정 상태는 [08 문서](08_DECISIONS_OPEN_QUESTIONS.md)에서 확인한다.
- 사실·개인 희망/사용자 조건·분석자 제안·팀 미결정을 구분한다.
- 미결정을 확정 요구사항·담당 배정·구현 완료로 바꾸지 않는다. 한 번 언급한 선택지를 개발 계획·시험 일정으로 확대하지 않는다.
- 미수행 기능·시험은 조건부 제안으로 쓰고 완료형 성과 예시를 만들지 않는다. 과거 프로젝트·외부 사례·문서 검수의 결과와 새 PBL의 실장비 결과를 구별한다.
- 자료 간 모순은 출처와 함께 알리고 최신 사용자 맥락과 대조한다.
- 과거 실습실 시나리오는 당시 예시다. 현재는 실습실 + 산업 10개 배경을 유지하며, 화재 관련 목표·채택 상태는 00·02·08·09와 대조한다.
- research 원본은 근거 없이 수정·삭제하지 않는다. 제안·회의 결정은 전달 문서에 기록한다.
- 현재 목적은 논의용 자료 검토다. 구현·배치는 사용자의 해당 요청 범위에 따른다.
- 한국어의 간결한 ‘-한다’체를 쓴다.

## 공통 질문과 배경 후보

> 여러 지점의 화재 위험 관련 상태를 확인해야 하는 사람이 있다면, 이동 로봇이 최신 증거를 확보하고 이상 신고 후 재확인·모의 후속 대응을 돕게 할 수 있을까? 어떤 항목이 실제로 보이고, 기존 방식보다 어떤 정보가 늘어나는지부터 시험하려 한다.

검토 배경은 **실습실 1개와 산업 현장 10개**로 유지한다. 후보 수는 선택 폭을 설명하기 위한 정리다. 모든 배경을 구현하거나 같은 비중으로 발표해야 한다는 조건은 추가하지 않는다.

## 실습실의 두 가지 쓰임

| 구상 | 실제 문제·사용자 | 먼저 확인할 질문 |
| --- | --- | --- |
| 실습실 자체의 운영 문제 | 마지막 이용자·관리자의 퇴실 확인, 충전 구역·장비 표시·통로 확인과 인계 누락 | 실제 반복 불편이 있는가? 사진으로 답할 수 있는 확인 항목이 있는가? |
| 실습실 안의 산업 모형 | 창고·공장 등 가정한 현장 담당자의 업무를 통제된 모형으로 시험 | 현장 업무의 어떤 부분을 재현했는가? 실제 사용자 요구를 확인했는가? |

실습실에도 사용자·불편·대안·검증 가능한 결과를 정의하면 PBL 후보가 성립할 수 있다. ‘안전해 보이는 사진’만으로 확인 업무를 끝냈다고 평가하면 문제 정의가 부족하다. 반대로 산업 이름을 붙였다는 이유만으로 현장 필요가 검증되는 것도 아니다.

실습실은 실제 접근·관찰·면담을 할 수 있는지부터 확인한다. 산업 모형은 자료에 근거한 업무 가설과 실험 가정을 명시한다. 두 경우 모두 조명·카메라 높이에 맞춘 결과와 실제 환경의 차이를 기록한다.

## 유지하는 11개 배경과 구체적인 확인 대상

아래 업무와 화재 관련성은 설계 가설이다. 산업별 실제 사고율·로봇 성능을 평가한 순위가 아니다.

| 배경 | 확인할 대상·사용자 | 화재 위험 관리와 연결할 부분 | 이동해서 얻을 정보·남는 질문 |
| --- | --- | --- | --- |
| 실습실 | 이용자·관리자의 장비 표시·충전 구역 외관·퇴실 확인 항목 | 확인 누락·후속 확인·인계 기록의 개선 | 여러 구역의 최신 표시. 체크리스트나 고정 카메라로 충분한가? |
| 물류센터·자동화 창고 | 시설 담당자의 적재·통로·충전 패널 | 가연물 적치·통로 방해·경보 확인 지원 | 변경된 적재의 다른 면. 높은 랙을 볼 수 있는가? |
| 배터리 제조·보관·충전 시설 | 안전 담당자의 보관함·충전기 경보·외관 | 경보 위치의 재확인과 증거 확보 | 해당 구역 최신 외관. 내부 이상은 어떤 센서·설비 데이터로 확인하는가? |
| 일반 제조공장·생산설비 | 보전 담당자의 표시등·계기·밸브 외관 | 설비 이상 표시의 확인·후속 요청 | 여러 로컬 표시·측면. PLC에서 이미 얻는 값과 무엇이 다른가? |
| 폐기물·재활용 선별시설 | 운영자의 보관·이송 구역 신고 위치 | 혼입 배터리 등 위험 맥락에서 현장 재확인 | 더미의 접근 가능한 다른 면. 내부 가림·잔해는 어떻게 처리하는가? |
| 목재·제지·가구 제조시설 | 시설 담당자의 적치·가공 주변·경고 표시 | 가연물·분진 관련 외관 점검 지원 | 변화한 적치·통로. 집진 내부·분진 위험을 따로 구분했는가? |
| 전기설비·변전설비 | 설비 담당자의 패널·계기·경고 표시 | 전기·열 이상 관련 표시의 확인 | 가려진 표시 추가 관측. 사진과 실제 전기 진단의 차이는 무엇인가? |
| 석유화학·정유·화학공장 | 운전원의 계기·밸브 표시·가상 누출 경보 | 분산 설비의 상태 확인·후속 요청 | 여러 관측 위치. 공정 지식·방폭·접근 조건을 확인할 수 있는가? |
| 전통시장·상가 | 관리자의 점포 외관·통로·야간 신고 | 열원·전기 관련 신고 재확인 | 점포별 다른 면. 닫힌 셔터 뒤·사생활·문턱 문제는 무엇인가? |
| 지하주차장·EV 충전 구역 | 주차 관리자의 충전기 표시·차량 주변 | 충전 구역 모의 경보와 현장 증거 연결 | 차량 배치별 측면. 차체 내부·경사·차량 동선은 어떻게 구분하는가? |
| 데이터센터·UPS 설비실 | 시설 담당자의 랙·UPS 패널·이전 기록 | 전원 관련 상태 변화의 확인·인계 | 여러 랙의 육안 표시. 기존 설비관리 시스템에 없는 정보인가? |

각 항목의 작은 완료형과 시험은 [11 문서](11_INDUSTRY_FEASIBILITY.md)에 둔다. 원문의 산업별 의견과 실제 사례는 [10 문서](10_INDUSTRY_FIRE_RESEARCH.md)에 보존한다. 물류·제조 우선 검토는 당시 분석자의 의견이며 장소 선정은 열려 있다.

## 화재 관심을 업무로 구체화한다

화재는 사용자가 전달한 팀원의 관심사다. **예방을 위한 점검 지원 → 이상 관측·신고의 재확인 → 모의 후속 대응**을 연결할 수 있으며 어느 부분을 중심으로 할지는 팀이 탐색한다.

사진 확보·표시 판독·실제 발열 감지·모형 투척은 각각 관측 수단과 성과가 다르다. 모형 대응 장치는 목적·기구·시험 조건을 별도로 검토한다. 단계의 첫 성과는 선택한 확인 업무를 끝내는 것으로 평가하고, 실제 감지·진압 주장은 그에 맞는 근거를 갖춘 뒤 판단한다. [목표 구분](02_PBL_GOALS.md#fire-goals)

## 비교할 세 축

| 축 | 확인할 근거 |
| --- | --- |
| 문제의 타당성 | 실제 사용자, 반복 빈도·누락·확인 후 행동, 기존 해결 방식 |
| 이동 관측의 추가 가치 | 고정 카메라·설비 데이터·사람의 방문과 비교한 추가 시야·정보·부담 |
| 교육용 구현·단계별 완결성 | 현재 카메라·통로·데이터로 첫 업무가 끝나는지, 실패 사유를 남길 수 있는지 |

배경이 화재 위험과 관련된다는 사실, 이동 점검 로봇 사례가 있다는 사실, 현재 로봇으로 해당 모형 업무를 구현할 수 있다는 판단을 각각 확인한다. 현장 사용자의 업무 빈도·경제적 효과는 인터뷰와 시험 전까지 가설로 둔다.

## 기존 조사에서 유지할 사실 구분

- NFPA 창고 통계와 산업·제조시설 통계는 기간·대상이 달라 산업별 발생률 순위를 만들 수 없다.
- 포스코 Spot은 사족보행형이며 현대차·변전소 연구에는 차륜형 사례가 있다.
- 우체국물류지원단 관련 보도는 배터리 화재 진압 장비 실증이다.
- 서울시의 85건은 2024년 테스트베드의 50℃ 이상 위험요인 감지 기록이다.
- 재활용·목재 시설의 위험·사고 자료와 해당 현장의 차륜형 화재순찰 실증은 별도로 확인한다.

날짜·출처·미확인 항목은 [10 검증표](10_INDUSTRY_FIRE_RESEARCH.md#verification)에 둔다. 이번 보완에서는 기존 외부 자료 전체를 새로 재검증하지 않았다.

## 이번에 탐색할 질문

- 실습실에서 실제로 겪는 점검·인계 불편이 있는가? 산업 후보의 어떤 업무와 비교할까?
- 화재 관련 관심 중 점검·재확인·모의 대응에서 각자 특히 해 보고 싶은 부분은 무엇인가?
- 두 로봇의 실제 지원 기능을 확인하면 어떤 추가 정보나 독립된 업무를 맡길 수 있을까?
- 같은 조건으로 비교할 촬영·기록 시험 하나를 고른다면 무엇이 좋을까?

TurtleBot3를 중심으로 JetBot MINI도 활용하는 방향을 기본 전제로 기획하고, 각 장비의 역할은 실제 지원 기능과 팀 논의로 구체화한다. ① 웹의 요청·공식 기록, ② 로컬 자료·분석, ③ 실행·수집·통신이라는 개인 희망은 유지한다. 로봇별 임무·프로그램 배치·스택은 [08 상태 기록](08_DECISIONS_OPEN_QUESTIONS.md)을 따른다. 구체적 선택은 시험·팀 논의의 준비 정도에 맞춰 진행한다.

# 기능 후보 1~27

## 표를 읽는 기준

모든 항목은 분석자의 **기능 후보**이며 팀 채택·개인 담당은 미결정이다. 1~24는 기존 번호와 제목을 유지하고, 25~27은 최근 개인 희망을 구체화한 추가 제안이다. 표의 책임과 최소 범위도 검토안이다. ②의 관심 수준은 [04 문서](04_DESKTOP_APP.md), 결정·변경 근거는 [08 문서](08_DECISIONS_OPEN_QUESTIONS.md)에서 관리한다.

## 중복을 줄일 연결 묶음

- **업무 완결** — 1·2·9에 4를 연결해 요청·관측·확인·후속 점검을 끝낸다.
- **로컬 분석** — 25로 자료를 확보하고 6·8·15 또는 17·19에서 실제 계산을 수행한다. 7·27로 정리하고 26으로 선택 제출한다.
- **상태 활용** — 16의 제공 기능 확인 → 5의 갱신·유효성 → 14의 작업별 준비 판단 → 15의 기록 조사로 연결한다.
- **기록 복구** — 9·10·11·12를 23·24의 실행·장애 시험과 연결한다.
- **모형 투척 채택 시** — 기구 시험을 선행하고 20의 조건 기록 → 21의 결과 검토 → 22의 보정 비교로 확장한다.

## 선행 조건을 해석할 때

16의 기능 조사와 23의 초기 환경 구축은 준비 활동이다. 실제 관측·분석 업무와 연결해야 PBL 성과를 평가할 수 있다. 모든 후보를 구현해야 한다는 의미는 없다.

10은 로봇 실행 측 → 서버의 관측 복구, 25는 서버 → PC의 자료 확보, 26은 PC → 서버의 분석 제출이다. 저장 데이터·실패 의미·처리 주체가 다르다. 공통 식별·검증 로직을 재사용할 수 있다.

사진 재촬영의 판단은 18, 후속 요청 관리는 4, 실제 실행은 9와 연결한다. 데이터 읽기·시간 선택·그래프는 3·6·8·15에서 공유할 수 있다. 앱이나 서비스의 분리는 실제 사용 목적·부하·장애 경계에 따라 결정한다.

로봇팔과 목 구동 안건은 함께 잠정 폐기 상태다. 20~22번의 모형 투척은 저렴한 서보모터를 이용한 투석기형 장치 등을 별도 후보로 검토하는 기능이다. 모형 투척의 명중 결과와 실제 소화 효과는 별도의 검증 대상이다. 열화상은 원래 24개 밖에서 언급된 선택 장비이며, 이번 목록에서 새 확정 기능으로 추가하지 않았다.

원본의 상세 선행 관계는 [책임 배치 표](research/feature_responsibility_analysis_2026-11-13.md#matrix), 25~27의 입력·인터페이스는 [PC 보완](research/desktop_app_direction_2026-11-14.md#additional)에서 본다.

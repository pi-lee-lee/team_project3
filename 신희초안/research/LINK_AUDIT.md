## Chieftain 표기·하드웨어 안건·ZIP 정보 점검

- 같은 인물을 가리키던 호칭과 주행 코드 보유자 표현을 Chieftain으로 통일하고, 별칭 설명은 최상위 README 첫 등장에 한 줄로 둔다. 다른 팀원을 가리키는 표현은 문맥에 따라 보존한다.
- 로봇팔과 목 구동은 최신 사용자 설명에 따라 함께 잠정 폐기로 기록한다. 직전 전달본에 남아 있던 목 구동의 미확정 표현을 정정했다. 저렴한 서보모터의 투석기형 모형 투척은 별도 후보로 유지한다.
- 수정 전 ZIP을 실제 압축 해제해 52개 파일과 작업 폴더의 바이트 일치를 확인한 뒤 정보 검사를 수행했다.
- IPv4 표기는 루프백 14회와 전체 인터페이스 바인딩 5회였다. 개인·기관 네트워크를 특정하는 실제 사설망·공인 주소는 탐지되지 않았다.
- 이메일 2회는 패키지 메타데이터의 예시 주소였다. 개인 홈 경로·전화번호·주민등록번호·인증정보 포함 URL·대표적 토큰·개인키·하드코딩 비밀번호 패턴은 검사 범위에서 발견하지 못했다.
- 비밀정보 파일명과 개인 식별용 계정 문자열도 검사했다. 지도 PGM은 표준 P5 파일이며 헤더 주석이 없었다. 원래의 실내지도·지도 설정은 참고 자료로 계속 포함한다. 지도 자체의 시설 배치 정보는 공유 범위를 판단할 때 함께 확인한다.
- 민감정보 때문에 제외하거나 익명화한 파일은 없다. 소스·설정 원본과 연구 사본의 해시는 보존한다. 이 결과는 패턴 검사·관련 문맥 검토 범위이며 모든 정보 위험이 없음을 보장하는 진술은 아니다.

## 원본 보존·정보 검사 범위

[출처 목록](SOURCES.md)에 기록된 전달용 연구 사본 12개의 SHA-256을 대조했다. 주행 부록의 소스·설정 사본 17개와 project_ws 원본도 기록된 해시와 대조했다. 작업공간의 원래 프로젝트·연구 파일에는 쓰기 작업을 수행하지 않았다.

이번에는 실제 ZIP에 포함된 문서·소스·설정과 파일명을 점검하고, 바이너리 지도는 형식·헤더를 확인했다. 주소·이메일 탐지는 문맥을 분류했다. 혼용 오타·링크·원본 보존도 별도로 검사한다. 패턴 검사의 한계는 위 정보 점검 범위에 따른다.

SOURCES의 원래 연구 자료 18개 무변경 설명은 이전 작업의 검수 기록이다. 이번에는 전달 사본 12개와 주행 원본 17개 대조를 수행했다. ZIP만으로 패키지 밖 원본 18개 전체의 과거 상태를 독립 검증할 수는 없다.

## 이전 검수 기록과의 관계

- 초기 연구 묶음에서 내부 링크 534개를 검사하고, 안내 페이지로 과도하게 우회한 링크 43개를 포함된 원문·앵커로 복구했다.
- 주행 부록 병합 뒤 49개 파일과 내부 링크 573개를 검사했다. 전체 프로젝트 참조 5개 예외를 기록했다.
- 산업 조사 09·10·11 추가 뒤 52개 파일과 내부 링크 597개를 검사했다. 당시 최종 숫자가 이 문서에 반영되지 않은 부분을 이번에 갱신했다.
- 위 숫자는 각각의 시점·범위에 해당한다. 이번 전달본 전체의 결과는 위 최종 검사 표를 따른다.
- 전달본에서 제외한 6개 자료와 이유는 [연구 안내](README.md#excluded)에 유지한다. 원래 작업공간 자료는 보존한다.

## 내용·외부 근거의 확인 한계

개인 희망·분석자 제안·팀 미결정을 구분했다. 실습실을 후보로 유지한 정리와 화재 관련 목표 구분은 회의 논의안이다. JetBot 활용은 최신 사용자 기획 전제이며, 실제 사용자 불편·장비 설치·동작·관측 성능·로봇별 임무·팀 채택·분업은 확인·합의할 사항이다.

제조사·NVIDIA·ROS·ROBOTIS 자료 확인은 이전 장비 보완의 조사 기록이다. 당시 ROS 문서 사이트의 접근 제한은 공식 저장소 원문으로 보완했다. 이번에는 미수행 시험·계획의 표현과 문서·ZIP을 검수했으며 외부 자료를 새로 재조회하지 않았다. 10에 기록된 산업 외부 URL·인증·문헌 전체를 새로 재조회하지 않았다. 기존 조사일·출처·미확인 항목은 [상세 조사](../10_INDUSTRY_FIRE_RESEARCH.md#verification)에 보존했다. 실제 센서·배포·실장비 성능을 새로 시험한 결과도 추가하지 않았다.

# 상세 연구 자료 안내

이 폴더는 기능·PBL 구상의 참고용 전달 사본이다. 과거 제안과 현재 개인 희망을 함께 보되 채택·구현·실장비 성공 여부는 [08 문서](../08_DECISIONS_OPEN_QUESTIONS.md)에서 확인한다.

## 과거 시나리오를 현재 맥락에 연결할 때

통합 회의안 등에 나오는 실습실 퇴실 점검은 당시 구체화한 예시로 보존한다. 현재는 실습실 자체의 문제와 산업 10개 배경을 함께 검토한다. 화재 관련 점검·재확인·모의 대응의 중심 업무도 미결정이다. JetBot MINI는 현재 활용하는 방향을 기본 전제로 기획한다. 보유 장비 문서의 Nano 4GB 기록을 참고하며 실제 설치 이미지·동작·임무는 확인·논의한다. 과거 사본의 조건부 참여 표현과 장비 설명은 [06 실행 환경](../06_INTERFACES_DEPLOYMENT.md#robot-environments)과 대조한다.

로봇팔과 목 구동은 최신 사용자 설명에 따라 함께 잠정 폐기 상태이며, 저렴한 서보모터를 이용한 투석기형 모형 투척은 별도 후보로 유지한다. 과거 자료의 하드웨어 제안은 [08 최신 상태](../08_DECISIONS_OPEN_QUESTIONS.md)와 대조한다.

과거 사본의 시험 항목·‘앞으로 할 계획’ 표현도 당시 제안으로 읽는다. 현재 팀의 확정 일정·담당과 구별한다. 과거 프로젝트·외부 기관의 시험 기록과 이번 자료의 파일·링크·ZIP 검수는 새 PBL의 환경 구성·실장비 시험 결과와 구별한다. Jazzy는 대화에서 한 번 언급한 선택지이며 최신 언급의 상태는 [08 상태](../08_DECISIONS_OPEN_QUESTIONS.md)를 따른다.

예전 자료에서 아이디어를 가져올 때 [00 첫 설명](../00_MEETING_BRIEF.md), [02 PBL 목표](../02_PBL_GOALS.md), [08 상태](../08_DECISIONS_OPEN_QUESTIONS.md), [09 배경 비교](../09_INDUSTRY_MEETING_BRIEF.md)를 대조한다.

## 패키지 밖 근거와 확인 한계

채용공고 전체·강의 수집본·과거 프로젝트 소스와 실험 환경은 미포함이다. 해당 근거가 필요한 경우 원자료를 별도로 확인한다. 원문의 미포함 자료 링크는 이 안내로 연결했다. 로컬 장비 README 참조는 포함된 사본으로 연결했다.

독립적인 사용자 작성 희망사항 파일·팀 확정 회의록·이전 붙여넣기 첨부 원문은 확보하지 못했다. 최신 사용자 요청과 AI가 정리한 요약의 출처를 구별한다. 실장비·JetBot 세팅·API·배포·성능은 이번에 새로 시험하지 않았다.

원래 자료는 보존하고 전달 사본에 참고용 안내, 경로 정리, 명백한 오타 교정만 적용했다. 수정·제외 내역과 해시는 [SOURCES](SOURCES.md), 링크·정보 점검은 [LINK_AUDIT](LINK_AUDIT.md)에서 확인한다.

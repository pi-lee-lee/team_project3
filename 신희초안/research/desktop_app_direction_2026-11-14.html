독립 PC 앱의 존재 이유

독립 PC 앱은 서버에 쌓인 사진·센서·로그·작업 기록을 사용자의 일반 로컬 폴더에 가져와, 여러 자료를 연결하고 반복 분석·검토·정리하는 작업공간으로 구상할 수 있다. 사용자는 확보한 자료를 서버 연결 없이 다시 열고, PC의 Python·OpenCV 등 분석 라이브러리와 기존 이미지 편집기·스프레드시트·에디터를 이용해 결과를 완성한다.

앱의 성과는 ‘작업 자료 가져오기 → 필요한 근거 찾기 → 설정을 바꾸어 처리·비교하기 → 메모·결과·보고 저장 → 필요한 결과를 선택해 서버에 제출하기’라는 반복 업무를 끝내는 데 있다. 실패 조사, 관측 품질 보정, 시험 회차 비교 등 여러 목적에 사용할 수 있다. 공식 업무 상태·원본 자료·로봇 실행의 책임은 기존 서버·실행 프로그램에 두고, PC는 확보한 자료와 로컬 분석 이력을 관리한다.

개인 희망은 이번 요청의 로컬 저장·폴더 관리·오프라인 분석·PC 연산·여러 작업 연결·복합 조사·결과 반영·외부 프로그램 연계다. 아래 기능 묶음·폴더·API·단계는 이를 구체화한 분석자의 제안이다. 최종 주제·팀 요구사항·개인 담당·기술 스택은 팀 미결정 상태다.

25. 작업 자료 가져오기와 로컬 작업공간

사용자·장면은 팀의 시험·분석 담당자가 작업 목록에서 필요한 자료를 골라 자신의 폴더에 보관하는 것이다. 입력은 작업·관측 목록, 고정 버전의 파일 목록, 사진·수치·이벤트·단위·시각 정보다. 결과는 오프라인에서 열 수 있는 자료 사본과 입력 목록이다.

인터페이스는 작업·자료 목록 조회, 버전 고정 파일 다운로드, 자료 묶음 명세다. 가장 작은 범위는 작업 한 건의 사진·이벤트·작은 센서 CSV를 내려받아 서버 연결을 끊고 앱을 재시작한 뒤 검토·메모·보고를 끝내는 것이다. 중단된 다운로드·해시 불일치·누락 자료·폴더 이동을 시험한다. 전체 자동 동기화와 모든 원시 기록 형식 지원은 이후 선택 범위로 둔다.

26. 로컬 분석 결과의 명시적 제출

사용자·장면은 로컬에서 만든 메모·표·판정·보고 중 공유할 결과를 선택하는 것이다. 입력 자료의 버전·해시와 설정·분석 모듈 버전을 결과에 연결하고 새 분석 결과로 서버에 제출한다. 공식 점검 확인·재점검 요청·운영 기준 적용은 별도 업무 절차를 거친다.

PC 가치는 로컬 처리와 외부 프로그램에서 만든 결과를 출처와 함께 업무 이력에 연결하는 데 있다. 파일 업로드 자체는 웹에서도 가능하다. 앱이 입력·설정·결과를 이미 알고 있으므로 사용자가 같은 내용을 재작성하는 부담을 줄일 수 있다.

최소 범위는 분석 결과 ID를 가진 보고 한 건을 사용자가 미리 보고 제출하고, 서버 수신 ID를 저장하는 것이다. 응답 유실 후 같은 결과 ID 재시도·원자료 버전 변경·다른 사용자의 업무 수정·오프라인 초안을 시험한다. 기존 결과를 바꾸는 경우 버전 충돌을 표시하고 사람의 판단으로 새 결과·수정·보류를 선택한다.

서버 자료를 가져와 분석·정리·반영하는 시나리오

설명용 상황으로 점검 사진이 불분명했던 작업과 정상적으로 촬영된 작업을 비교한다. 실제 최종 주제·로봇 임무·수치 성능은 아직 결정되지 않았다. 두 로봇의 자료가 있다면 파일에 기록된 로봇 ID와 지원 정보를 보존해 같은 작업공간에서 읽는다.

  1. 작업 선택과 가져오기. 분석 담당자가 앱에서 서버의 두 작업을 선택하고 저장할 폴더를 고른다. 자료 목록·버전을 확인해 사진·센서 CSV·이벤트를 받는다. 센서가 제공되지 않는 항목은 자료 없음으로 기록한다.
  2. 로컬 완전성 확인. 앱이 받은 파일과 명세의 크기·해시·누락을 확인하고 오프라인에서 가능한 분석을 표시한다. 선택한 자료를 모두 확보해야만 모든 메뉴가 동일하게 가능하다고 표시하지 않는다.
  3. 서버 연결 없이 다시 열기. 네트워크를 끊거나 서버를 종료하고 앱을 다시 실행한다. 작업공간에서 당시 사진·시각·이벤트·지원 센서값을 찾아 촬영 당시의 흔들림·어두움·전송 문제 가능성을 조사한다. 관측 사실과 추정 원인을 나눠 메모한다.
  4. 외부 도구 이용. 센서 CSV를 스프레드시트에서 확인하고 사진의 사본을 이미지 편집기로 연다. 결과 파일을 선택해 해당 작업의 분석에 첨부한다. 원사진에 대한 ROI와 외부에서 크기가 바뀐 이미지의 좌표를 혼용하지 않는다.
  5. 기준 비교. PC에서 설정 A와 B를 저장하고 같은 사진 묶음에 적용한다. 사람 라벨과 다른 사진을 모아 검토하고 비교표·오류 목록·보고를 저장한다. 중단된 처리는 완료 결과와 구분한다.
  6. 로컬 결과 완결. 입력·설정·분석 버전·근거·메모·보고를 한 분석 실행에 연결한다. 이 시점에 서버에 제출하지 않아도 담당자가 조사 보고와 비교 결과를 이용할 수 있다.
  7. 서버에 선택 제출. 연결을 복구하고 공유할 분석 결과를 미리 본 뒤 새 첨부 결과로 제출한다. 원본 자료 버전과 현재 서버 상태가 달라도 과거 스냅샷 분석임을 명시한다.
  8. 필요한 업무 반영. 공식 확인 결과나 운영 기준을 수정하려면 최신 상태를 조회한다. 다른 담당자의 변경이 있으면 차이를 검토해 새 제안·수정·보류를 선택한다. 웹에서 새 분석 결과와 근거를 확인하고 실제 후속 작업을 정한다.

# 프로젝트 배경과 현재 구상

## 배경

로봇·웹·PC 앱·통신·데이터 처리에 걸친 개발 성과를 하나의 실제 문제 해결 과정에서 남기려는 구상이다. 사용자는 기존 로봇 통합 경험을 바탕으로 새 모듈을 설계·구현·시험할 기회를 원한다.

현재는 여러 지점의 화재 위험 관련 점검·이상 재확인·모의 후속 대응을 연결하는 문제군을 검토한다. 화재에 관심을 보인 팀원이 있다는 사용자 설명을 반영한 논의안이며 중심 업무·장소·로봇 임무는 미결정이다.

배경 후보는 실습실 1개와 산업 현장 10개로 유지한다. 실습실 자체의 퇴실·장비 표시·충전 구역 확인을 개선하는 안과, 산업 업무를 실습실 안의 모형으로 시험하는 안을 구별한다. 실제 사용자와 관측 대상·대안·첫 완료 단위를 확인해 범위를 좁힌다. [11개 배경 비교](09_INDUSTRY_MEETING_BRIEF.md)

이전 통합안의 ‘실습실 퇴실 점검’은 당시 검토 예시로 보존한다. 과거 문서를 맥락으로 활용할 때는 [08 최신 상태](08_DECISIONS_OPEN_QUESTIONS.md)와 대조한다.

## 현재 조건의 출처

이 패키지는 사용자가 이번 요청에서 전달한 구상을 최신 맥락으로 삼는다. 개인 희망을 정리한 이전 문서도 AI가 작성한 요약이므로 팀 합의를 증명하는 자료로 사용하지 않는다. 상태·출처·이전 문서와의 차이는 [08 문서](08_DECISIONS_OPEN_QUESTIONS.md)에서 관리한다.

## 설명을 위한 전체 흐름

    사용자 → ① 웹·업무 API·공식 기록
                      ↕ 작업 요청·실행 관측·파일
                 ③ 실행·수집·장치 연동 ↔ 로봇

    사용자 → ② PC 앱 ↔ ① 허용된 자료·결과 API
              ↕
          일반 로컬 폴더 ↔ 로컬 분석·외부 프로그램

책임을 설명하는 그림이다. 프로세스 수·실행 위치·전송 기술은 [06 문서](06_INTERFACES_DEPLOYMENT.md)의 선택지로 남긴다.

## 장비와 범위

- TurtleBot3를 중심으로 검토한다. 카메라·LiDAR·별도 PC를 활용할 수 있다는 사용자 설명이 있다.
- JetBot MINI는 활용하는 방향을 기본 전제로 기획한다는 최신 사용자 설명을 따른다. 보유 장비 README는 Jetson Nano 4GB·TT 모터 2개·IMX219 카메라로 기록한다. 실제 임무·연동 방식은 세팅 결과와 팀 논의로 구체화한다.
- 추가 웹캠은 가능성이 있으며 실제 모델·장착·촬영 조건은 미검증이다.
- 기존 센서·상태값을 활용하고 새로운 STM32 보드를 필수 요소로 삼지 않는다.
- 로봇팔과 목 구동 안건은 최신 사용자 설명에 따라 함께 잠정 폐기 상태로 기록한다.
- 저렴한 서보모터를 이용한 투석기형 모형 투척은 별도 후보로 유지한다. 채택·기구·시험 범위는 팀과 논의한다.
- 자동 판정·열화상 등은 기존 미확정 상태로 두며 실제 필요·장비·기구 검증을 따로 판단한다.

보유 장비 문서의 사양을 참고 기준으로 삼고 설치 이미지·SDK·제어·촬영·상태 조회의 실장비 결과를 별도로 기록한다. 제조사 자료에 2GB·4GB 구성이 모두 있어 보유 문서의 4GB와 2GB 제품 소개를 구성 차이로 해석할 근거가 있다. [장비 설명 사본](research/team_project3_README.md), [환경·공식 자료](06_INTERFACES_DEPLOYMENT.md#robot-environments)

## 개인 경험을 해석하는 범위

사용자가 설명한 이전 담당은 STM32 출력 장치·시리얼 연동·음성 기능·통합·시험·자동화다. 자율주행·YOLO·웹/DB의 주요 구현은 팀원 담당이었다. 현재 자료는 새 프로젝트에서 해당 구현 능력과 재사용 성공을 보증하지 않는다.

## 자료의 성격

이 패키지는 기획·회의용 문서다. 기능 후보·완료 기준·시험은 앞으로 선택하고 검증할 계획이다. 이전 채용·강의 분석은 아이디어의 배경으로 보존하며, 현재 공고·자격·숙련도의 재평가로 확대하지 않는다. 원본 안내는 [research/README](research/README.md)에서 본다.

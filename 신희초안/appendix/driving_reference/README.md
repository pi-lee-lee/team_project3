# 부록 · 이전 주행 코드의 선택적 참고

**최종 프로젝트의 주행은 Chieftain이 작성한 기존 코드를 중심으로 진행할 가능성이 크다.** 이 부록은 필요한 세부 설정값이나 처리 방식을 찾아볼 때 사용하는 참고 자료다. 적용 필요성은 현재 주행 결과와 Chieftain의 판단을 기준으로 정한다.

> Chieftain의 주행 코드를 중심으로 진행할 생각이다. 예전 코드의 속도·여유 거리 같은 값이 필요할 때 참고가 될 수도 있어 부록으로 넣었다.

Chieftain의 소스는 아직 제공되지 않았다. 코드 비교·채택 결론은 없으며, 이 부록의 설정값·기능은 최종 프로젝트의 요구사항으로 추가된 것이 아니다. 본문 회의 자료를 읽은 뒤 관심 있는 부분만 선택해 본다.

## 먼저 세부 값만 보고 싶다면

[PARAMETERS.md](PARAMETERS.md)에서 속도·가감속·추종 거리·장애물 여유 값을 확인한다. 현재 적용 위치와 덮어쓰기 여부를 함께 적었다. 값의 적합성은 로봇 크기·지도·센서 장착·환경에 따라 판단한다.

## 먼저 볼 파일

- [smooth_base.py](source/src/my_bot_fall/my_bot_fall/smooth_base.py) — 지도·A*·추종·회피·속도 제한의 기본 클래스.
- [fall_patrol.py](source/src/my_bot_fall/my_bot_fall/fall_patrol.py) — 위 클래스를 상속해 반복 순찰·웹 명령·자세 관찰·사건 처리를 연결.
- [파라미터](PARAMETERS.md) — 실제 적용값과 변경 위치.
- [기존 실행 환경](RUNNING.md) — 토픽·TF·외부 프로그램과 이식 시 확인 사항.
- [코드 근거](EVIDENCE.md) — 원본 경로·줄 번호와 실제 실행 관계.
- [복사 파일 목록](SOURCE_INDEX.md) — 보조 파일의 필요성·원본 해시.

실행 진입점은 **ros2 run my_bot_fall patrol → fall_patrol.main() → FallPatrol(AStarDriver)**다. 서버 PC의 한 노드에서 부모·자식 코드가 함께 동작한다. ROS 노드 이름은 부모가 지정한 astar_driver_yolo다.

## 필요할 때 참고할 처리 항목

| 부분 | 우리 코드에서 볼 동작 |
| --- | --- |
| 지도·A* | 장애물 부풀리기, 벽 근접 비용, 대각선 모서리 통과 제한 |
| 추종점 | 로봇→추종점 선분이 벽을 통과하면 보이는 경로점으로 단축 |
| 속도 | 목표·회전·전방 장애물에 따른 감속, 선속도·각속도 변화량 제한 |
| 회전·회피 | 제자리 회전 진입/해제 기준 분리, 한 회피 구간의 방향 유지 |
| 웹 정지·재개 | 순찰 지점·인덱스 보존, 현재 위치에서 목적지까지 새 경로 계산 |
| 실행·차단 | 정지와 속도 발행 직렬화, 센서·자세·서버 상태를 마지막 발행 경로에서도 검사 |

세부 구현이 궁금할 때 볼 함수 설명과 비교 질문은 [EVIDENCE](EVIDENCE.md)에 있다. 기존값의 적합성은 새 로봇의 크기·지도·라이다 장착·제동 특성·사용 환경에서 판단한다.

## 읽을 때 중요한 점

- 실제 FallPatrol은 별도 자세 판정 노드의 결과를 받는다. 부모의 YOLO 워커 초기화 경로는 오버라이드된다.
- localization_timeout_sec는 기본 2초로 선언되지만 현재 코드의 위치 유효성 검사는 위치값 존재만 확인한다. 설정만으로 AMCL 갱신 중단을 검출한다고 해석하면 안 된다.
- 웹 정지 후 이동 중 목적지는 유지한다. 도착 대기 중 정지하면 다음 지점으로 재개한다.
- 정상 자세가 일정 시간 확인되면 관찰에서 순찰로 복귀할 수 있다. 경고 사건이 생성된 경우에는 웹 조치와 조건 확인 뒤 새 시작 명령을 기다린다.
- 본 자료는 발췌 참고 묶음이다. 자세 판정·음성 노드 구현, 모델, 서버, 로봇 드라이버 등은 기존 전체 환경에서 준비한다. setup.py는 이러한 원래 패키지 구성을 포함한다.

원본 사본은 바이트 그대로 복사했다. 원문 README의 링크·실행 설명은 전체 프로젝트 배치를 기준으로 읽는다. 이번 작업은 정적 조사이며 새 실기·성능 시험 결과는 추가하지 않았다.
